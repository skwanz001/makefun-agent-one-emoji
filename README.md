One emoji that stands for the AI agent: 🎯 DIRECT HIT.

A chatbot answers. An agent is given a target and does not stop until it hits it — read, act, check, retry, ship. The target is the whole difference between an LLM and an agent, in one glyph: goal-directed, persistent, instantly readable at small size, and nothing like the robot or smiley half the field will send.

## Run it

```sh
python3 main.py
```

Writes the single glyph to `/output/entry.txt` (stdlib only, no dependencies).
